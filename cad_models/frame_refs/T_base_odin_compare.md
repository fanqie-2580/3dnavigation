## 3. 对比结论

| | CAD (SW) | 当前运行推算 |
|--|----------|--------------|
| 参考原点 | Go2 URDF **几何中心** | Mid-IMU `body` + 俯仰 TF（**不是** URDF base） |
| 平移 | 后 279 / 上 126 mm | 前 ~140–160 / 上 ~65–100 mm |
| 姿态 | 约绕 Y 180° | 约 yaw 13° + 小 pitch |
| ‖Δt‖ | — | **≈ 420–440 mm** |
| 相对转角 | — | **≈ 167–180°** |

### 平移其实对得上（换原点后）

Mid 装在机身**后部**拓展坞。运行链以 Mid-IMU 为原点，Odin 在 Mid **前** 150 mm → `t_x>0`。  
CAD 以机身几何中心为原点，Odin 在中心 **后** 279 mm → `t_x<0`。  

粗算：若 Mid lidar ≈ base 后方 ~0.43 m，则  
`x_odin ≈ -0.43 + 0.15 ≈ -0.28`，与 CAD **-0.279 m** 同量级。  
**差异主要是参考系原点，不是卷尺量错了前后。**

### 姿态仍不可直接互替

CAD 的 `diag(-1,1,-1)` 与卷尺/ICP 的 `Rz(12.8°)` 差约 180°。  
可能原因：SW 装配时 Odin STEP 轴向/朝向与官方 `L`（X 前、Y **右**、Z 上）不一致。  
**在 SW 轴向复核前，不要把 CAD 的 R 写进 Mid 融合的 `extrinsic_R_L2_wrt_L1`**（会把已对齐的 `/odin1/cloud_in_map` 翻掉）。

## 4. 实机测量（**不经过 Mid360**）

数据源（2026-11-05）：
- Go2：`lf/lowstate` / `lf/sportmodestate`（宇树 body IMU ≈ `base_link` 轴向）
- Odin：`/odin1/odometry`（child=`imu`）+ 官方 `T_imu_lidar`（t=[-0.02663, 0.03447, 0.02174], R=I）
- Odin `/odin1/imu` 的 orientation 恒为单位四元数，**不能用**；加速度可用
- 当前 `body_height≈0.076 m`、mode=0 → 狗基本是趴着/阻尼，不是站立

### 姿态（相对重力，两传感器独立 AHRS）

| | roll | pitch | 备注 |
|--|------|-------|------|
| Go2 body | ≈ 0° | ≈ **-5.8°** | lowstate.rpy |
| Odin imu（odom） | ≈ -0.8° | ≈ **+4.6°** | /odin1/odometry |
| 重力对齐相对 R | ≈ 数度内近 I | | 最小旋转把 Odin 重力转到 Go2 重力 |
| CAD R | ≈ **绕 Y 180°** | | `diag(-1,1,-1)` |

相对 CAD 转角：**≈ 174–179°**（实机两者都大致 Z 朝上；CAD 把 Z 翻了）。

结论：在「不用 Mid」的实机姿态观测下，**Odin 与 Go2 base 接近同向安装（小俯仰差）**，与 CAD 的 180° 绕 Y **明显不符**（更像 SW 装配轴/朝向反了）。

> 两路 AHRS 的 **yaw 零点独立**，因此 **相对 yaw 测不准**；上面结论主要看 roll/pitch / 重力方向。

### 平移

静止双 IMU **求不出** \(t_{xy}\)（没有公共平移参考，且禁止用 Mid 链）。

点云粗估（`/odin1/cloud_raw`，frame=`odom`，近水平）：
- 地面约在 \(z\approx-0.24\,\mathrm{m}\) → 雷达离地约 **0.24 m**
- CAD：Odin 相对 base 高 **0.126 m**；趴着时 base 离地约 0.05–0.08 m → 预期离地约 **0.18–0.20 m**
- 量级同阶，差约 **4–6 cm**（趴姿 + odom 非严格 L 系，仅粗比）

**CAD 平移** `t≈[-0.279, 0, 0.126]` **本次无法用实机无数据独立复验 xy**。
